Um projeto tecnológico que combina eletrónica, programação e automação para criar uma experiência de Air Hockey interativa e divertida.

Conhecer o Projeto

Sobre o Projeto

Este projeto consiste no desenvolvimento de uma mesa de Air Hockey, utilizando diferentes componentes eletrónicos e sistemas de controlo. O objetivo é criar uma mesa funcional capaz de detetar e acompanhar a interação dos jogadores durante uma partida.

Eletrónica

Utilização de sensores, LEDs, motores e outros componentes eletrónicos para o funcionamento da mesa.

Programação

Desenvolvimento do código responsável pelo controlo e funcionamento dos diferentes componentes.

Automação

Integração dos componentes para criar um sistema automático, interativo e funcional.

Objetivo

O principal objetivo é desenvolver uma mesa de Air Hockey que demonstre conhecimentos adquiridos nas áreas de eletrónica, automação e programação, criando um projeto prático, moderno e interativo.
